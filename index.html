Arsitektur Sistem

Detail integrasi perangkat keras dan perangkat lunak yang membentuk ekosistem SmartFarm.

Mikrokontroler Utama

ESP32-S3 WROOM. Mengelola akuisisi data sensor via protokol RS485 Modbus dan transmisi data WiFi.

Database Utama

Google Spreadsheet. Berfungsi sebagai basis data deret waktu (Time-Series Database) yang ringan.

Middleware / API

Google Apps Script (GAS). Menjembatani permintaan HTTP GET/POST antara ESP32, Dashboard, dan Spreadsheet.

Frontend Dashboard

Single Page HTML5, Vanilla JavaScript, TailwindCSS, dan Chart.js untuk visualisasi data interaktif.
